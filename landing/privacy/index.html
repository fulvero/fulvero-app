Политика конфиденциальности

Fulvero обрабатывает данные компаний и пользователей только для работы сервиса: авторизации, управления товарами, поставками, задачами, чатами, аналитикой и подпиской.

Какие данные обрабатываются

Название компании, данные сотрудников, email, роли, настройки доступа, данные Ozon-интеграции, товары, поставщики, поставки, производственные задачи, сообщения и журнал действий.

Интеграция с Ozon

Ozon Client ID и API-ключ хранятся в защищенном виде. Один Ozon ID нельзя подключить к двум разным компаниям.

Хранение и безопасность

Данные разделяются по компаниям. PostgreSQL работает в Docker, автоматические бэкапы хранятся 30 дней.
